# 🌌 Sagar Mahajan — 3D AI/ML Systems Portfolio

> A full-screen interactive 3D portfolio for **AI/ML Engineer & Systems Architect Sagar Mahajan**, built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Three.js (WebGL)**.

---

## ✨ Features & Architecture

- **10,480-Node 3D Neural Particle Avatar Engine:** GPU hardware-accelerated point cloud in Three.js with real-time 3D orbit kinematics, harmonic breathing waves, and click-to-disperse shockwave physics.
- **VisionOS 3D Parallax Case Study Cards:** True spatial 3D card tilt (`preserve-3d`), floating depth layers (`translateZ`), and real-time holographic specular light sheen.
- **Interactive 3D Synaptic Skill Matrix:** Real-time Three.js graph rendering glowing synaptic nodes and electrical axon connections across 4 AI domains.
- **3D Kinetic Circuit Timeline:** Energy conduit rail illuminating career trajectory on scroll.
- **3D Holographic Command Console:** Direct communication hub with 1-click **Gmail Web Compose** integration, live India Standard Time (`Asia/Kolkata`) telemetry, and zero form friction.
- **Universal Responsiveness:** Fluid layouts calibrated across Mobile (320px–640px), Tablets (640px–1024px), Laptops (1024px–1440px), and 4K Ultrawide displays.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15.5+ (App Router, Static Site Generation)
- **Frontend & UI:** React 19, TypeScript, Tailwind CSS, Lucide Icons
- **3D Graphics & Physics:** Three.js, WebGL, Custom GLSL Point Sprites & Shaders
- **Animations:** GSAP (ScrollTrigger, Flip), Lenis Smooth Scroll
- **Deployment:** Vercel Optimized (Zero configuration)

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/fncreator22/3D-Portfolio.git
cd 3D-Portfolio
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## 🌐 Deployment on Vercel

This repository is pre-configured for one-click deployment on **[Vercel](https://vercel.com)**:
1. Import this repository in your Vercel Dashboard.
2. Select Framework Preset: **Next.js**.
3. Click **Deploy**.
